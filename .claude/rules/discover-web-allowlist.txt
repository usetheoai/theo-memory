# noting why the domain is trusted (added because X for {slug} at {date}).

# - Subdomains are NOT auto-allowed. If you cite `spec.modelcontextprotocol.io`, that subdomain
#   needs its own entry (the root `modelcontextprotocol.io` does NOT cover it).
# - Citing a URL outside the allowlist caps /discover-confidence at 49 (INVALID) with stable
#   identifier `domain_not_in_allowlist` per cycle-discover.md v1.1 hard gate #5.
# - Drive-by domain additions defeat the audit purpose — every entry needs the inline rationale.
# - Adding an entry requires the rationale to cite the discovery slug + date.
# - Removing an entry requires explaining what blueprint(s) lose access.
