## Release notes

### Added
- **Zero-config `createMemory` preset**: `createMemory({ postgres, openai })` boots a working in-process `Memory` from just a Postgres URL + OpenAI key — it wires `OpenAIEmbedder` + `OpenAILLM` + `PgvectorStore` + a `pg.Pool`, auto-runs migrations by default (opt-out `{ migrate: false }`), owns the pool lifecycle (`dispose()` also ends the pool), and returns a `DisposableMemory`. Non-breaking: `createMemory` now accepts EITHER the preset shape OR the existing full `LocalMemoryConfig` (discriminated by the `postgres` field); `createLocalMemory` and existing callers are untouched. New public exports `CreateMemoryPresetConfig` (type) + `InvalidPresetConfig` (typed error thrown fail-fast on an empty `postgres`). One OpenAI key per process (the OpenAI client is a module-global lazy singleton); for multiple keys use the full-config path.
