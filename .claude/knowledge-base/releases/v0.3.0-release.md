## Headline

Consumer-DX fix: `@usetheo/memory` now ships built `dist/**` (exports/types point at dist) so Node-SSR consumers (TheoKit / Next / any Vite-SSR app) can resolve the package — a src-only package was unresolvable once a bundler externalizes the dep (Node cannot execute raw `.ts`). The published tarball also ships the dist drizzle migrations (`*.sql` + `meta/_journal.json`) so a post-install `runMigrations()` resolves the journal.

A `/review` (4 parallel agents) caught a BLOCKER the local live round-trip had masked: the build copied the migrations into dist on disk, but the `files` allow-list excluded them from `npm pack` → `runMigrations()` would have thrown `Can't find meta/_journal.json` for every published consumer (regression of the previously-closed EC-1). Fixed inline (files globs + `prepack` + positive pack-manifest assertion) before the release was cut.
