## Release notes

### Added
- **Cross-repo skills listing (`GET /v1/scopes/skill/:subject/all` + `Memory.listSkillsBySubject`).** Tenant-safe flat listing of ALL skills for a subject across every repo, each row carrying its `repoId`; offset pagination + optional `q` filter + `total`/`truncated`. Tenant isolation via `agent_id` prefix scan (LIKE-wildcards escaped + `ESCAPE '\'`) AND `workspace_id`; subject with `:` → 400. Additive (per-repo path byte-unchanged; no schema/migration/dependency). GOAL vs real ankane/pgvector:v0.5.1 (alice×3 across 2 repos + bob×1 → alice gets 3, none of bob; wildcard-escape + strict-prefix isolation). /review 4 agents → READY_TO_MERGE (COR-1 fixed inline; SEC-1 perf documented as additive follow-up).
