## Scope shipped

**Feature**
- Selectable runtime embedder via `THEOMEM_EMBEDDER` (`local` Xenova 384 default | `openai` text-embedding-3-small 1536). The openai path pulls no @xenova/onnx/sharp at runtime and makes no HuggingFace cold-start download. Only the chosen backend is lazy-imported; unknown values fail loud.

**Fixes (production-readiness batch + `/review`-caught regressions)**
- `Memory.reset(scope)` again purges soft-deleted rows (list-fix regression closed via opt-in `includeSoftDeleted`). (F-dom-mem-1)
- Destructive embedding-dim change now FAILS CLOSED on a populated DB unless `THEMEMORY_ALLOW_DESTRUCTIVE_DIM_CHANGE=1` (prevents env-toggle data loss). (F-dom-cli-1)
- `themory migrate` is embedder-aware (dim matches `THEOMEM_EMBEDDER`). (F-wire-1)
- `getAll`/`list` (scopes endpoint, OpenMemory `list_memories`, dashboard, reflection, eviction) excludes soft-deleted rows, matching recall.
- Clean-checkout build restored (`build:core` before main `tsc`).
- Docker image build restored (`.dockerignore` un-excludes `pnpm-lock.yaml` + `scripts/`; Dockerfile copies all packages).
- Docker runtime embedder fixed (`INCLUDE_OPTIONAL=true` ships `onnxruntime-node`; `TRANSFORMERS_CACHE` for distroless nonroot).

**Docs**
- README: OpenMemory-compatible mode section + selectable-embedder bullets + roadmap rows; refreshed stale test counts + Docker tag.
