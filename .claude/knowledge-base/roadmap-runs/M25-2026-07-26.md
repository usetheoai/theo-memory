# Milestone M25 — Config em camadas + `themory config` CLI (paridade mem0)

## Objective (from ROADMAP.md)

Layered config resolution (defaults → `~/.themory/config.json` global → `./.themory.json`
project → env → CLI flags; later wins) with per-key source-attribution and strict secret
discipline, plus a `themory config init|set|get|list` subcommand — closing the mem0-parity
Configuration gap (cross-validation dimension 2.5/5).

## Definition of done (from ROADMAP.md) — all met

- [x] 5-layer deep-merge resolver with `{value, source}` per key (`@usetheo/memory/config`:
  `resolveConfig`, `loadConfig`).
- [x] `themory config init|set|get|list`: `set` REFUSES secret keys (env-only); `get`/`list`
  mask secret values and show the winning source layer.
- [x] Real consumer: `themory server` resolves `THEOMEM_PG_URI` through the resolver (env still
  wins — env-only deployments byte-identical; `.themory.json` honored only when env unset).
- [x] Secret leakage & precedence-confusion guarded: file layers stripped of secret keys before
  composition; `saveProjectConfig` strips on write (defense-in-depth); malformed config fails
  loud with a typed `ConfigParseError` naming the file (never a silent empty).
- [x] Subpath registered in `scripts/rewrite-dist-aliases.mjs`; smoke-resolves with 11 exports.
