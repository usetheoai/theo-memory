§2.3 Iteration semantics: "until self-verification validates the task's completion, at which point we add this new skill to the skill library." After 4 failed rounds, curriculum proposes a different task.

§2.2 Skill library API:
- add_skill: "we add it to the skill library, represented by a vector database" — "The key is the embedding vector of the program description (generated by GPT-3.5), while the value is the program itself"
- retrieve_skill: "we perform querying to identify the top-5 relevant skills" using "the embedding of self-generated task plans and environment feedback"

Three feedback types:
- Environment feedback: "intermediate progress of program execution"
- Execution errors: "invalid operations or syntax errors in programs"
- Self-verification critique: "provides a critique by suggesting how to complete the task"
