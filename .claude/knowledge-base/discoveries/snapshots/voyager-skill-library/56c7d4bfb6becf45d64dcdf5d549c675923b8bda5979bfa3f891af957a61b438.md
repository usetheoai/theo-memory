§3.1 Four-type taxonomy (cites Sumers et al. 2024 CoALA):
- Working: "Whatever fits inside the current context window"
- Episodic: "Records of concrete experiences: individual tool calls, conversation turns, environment observations"
- Semantic: "Abstracted, de-contextualized knowledge"
- Procedural: "Reusable skills and executable plans"

§6.8 Software engineering agents:
"Software engineering agents lean heavily on procedural memory (verified code patterns and architecture decisions)."
Also §6.2: "Coding agents...Memory requirements are steep: retain architecture decisions, track bug report histories, remember code-style preferences."

§5.2-5.3 Benchmarks (4):
- LoCoMo (2024) — long-term conversational, no procedural metric
- MemBench (2025) — factual vs reflective, no procedural focus
- MemoryAgentBench (2025) — 4 cognitive competencies + selective forgetting, no procedural test
- MemoryArena (2026) — multi-session agentic tasks, implicit coding/planning
§5.5: "Nobody evaluates forgetting well. Only MemoryAgentBench tests selective forgetting explicitly."

§6.1 Forgetting (relevant v0.4b):
