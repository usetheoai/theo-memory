## Abstract summary

- Dataset: very long-term multi-turn conversations averaging 300 turns / ~9k tokens over up to 35 sessions
- Machine-human pipeline: LLM-based agents + personas + temporal event graphs + multimodal
- Tasks: QA, event summarization, dialogue generation
- 15% utterance corrections + 19% image substitutions by human annotators
- Findings: long-context LLMs + RAG improve 22-66% on QA but lag humans by 56%; temporal reasoning gap 73%; significant hallucinations on adversarial Qs
