## Abstract (paraphrased from WebFetch)

LongMemEval is a benchmark with 500 curated questions testing five core long-term memory abilities of chat assistants:

1. Information extraction
2. Multi-session reasoning
3. Temporal reasoning
4. Knowledge updates
5. Abstention

Existing systems show "a 30% accuracy drop on memorizing information across sustained interactions." Optimizations proposed at indexing / retrieval / reading stages.
