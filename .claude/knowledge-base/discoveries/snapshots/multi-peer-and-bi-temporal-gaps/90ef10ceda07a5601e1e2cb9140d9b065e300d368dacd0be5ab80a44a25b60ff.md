## API shape analysis
The temporal filter is a **DNF (OR of ANDs)** structure: `list[list[DateFilter]]`:
- Outer list = OR-clause (alternatives)
- Inner list = AND-clause (conjunction of date constraints)
- Each `DateFilter` = `{date, comparison_operator}`

**This is NOT a simple Zep-paper-style `asOf(timestamp)` API.** It's a more general date-range/DNF filter applied via the 4 temporal columns (valid_at, invalid_at, created_at, expired_at). Consumers compose `asOf(T)` themselves as `valid_at <= T AND (invalid_at IS NULL OR invalid_at > T)`.
