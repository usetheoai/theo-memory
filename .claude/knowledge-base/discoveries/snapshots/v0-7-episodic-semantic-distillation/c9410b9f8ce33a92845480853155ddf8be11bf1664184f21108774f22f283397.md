# Zep + Graphiti — Temporal Knowledge Graph Architecture for Agent Memory

## Architecture (verbatim claims)

"Memory is powered by a temporally-aware dynamic knowledge graph G = (N, E, ϕ), where N represents nodes, E represents edges, and ϕ : E →N × N represents a formal incidence function. This graph comprises three hierarchical tiers of subgraphs: an episode subgraph, a semantic entity subgraph, and a community subgraph."

## Episodic vs Semantic — explicit two-layer model

- **Episodic nodes:** contain the raw data of an episode. An episode is a single text-based event added to the graph — unstructured text (message, document paragraph) or structured JSON. Preserves full context.
- **Entity (Semantic) nodes:** semantic subjects/objects extracted from the episode. People, places, things, ideas — one-to-one with real-world counterparts.

## Ingestion process

"Graphiti builds its database by ingesting episodes... As the system processes these episodes, it forms or updates the graphs semantic relationships (edges) and entities (nodes)."

## Temporal handling — explicit invalidation

"Knowledge graphs can explicitly model these relationships with temporal validity periods, allowing facts to be invalidated when contradictory information arrives later." — THIS IS ZEP CLAIMING CONFLICT-RESOLUTION via bi-temporal validity periods.

## Search

Hybrid: semantic + BM25 + graph-based with result fusion. <100ms latency. Rerankers: Reciprocal Rank Fusion, Maximal Marginal Relevance, Node Distance, Episode Mentions.

## Benchmarks

- DMR (MemGPT-established): Zep 94.8% vs MemGPT 93.4%
- LongMemEval (also evaluated; no specific numbers in this blog)
