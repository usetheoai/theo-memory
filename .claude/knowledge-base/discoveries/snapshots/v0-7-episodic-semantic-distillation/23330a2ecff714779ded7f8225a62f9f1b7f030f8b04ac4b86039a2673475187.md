# MemoryBank: Enhancing Large Language Models with Long-Term Memory

**arXiv:** 2305.10250v3  |  **Published:** May 2023

**Authors:** Wanjun Zhong, Lianghong Guo, Qiqi Gao, He Ye, Yanlin Wang
**Code:** https://github.com/zhongwanjun/MemoryBank-SiliconFriend

## Abstract / key contributions

Addresses LLM limitation: lack of long-term memory mechanism for sustained interaction (personal companion systems, psychological counseling). MemoryBank enables models to summon relevant memories, continually evolve through continuous memory updates, comprehend, and adapt to user personality by synthesizing information from past interactions.

## Memory architecture (3-part system)

1. **Storage** — saves daily chats, event summaries, and user personality and mood assessments
2. **Retrieval** — encodes dialogues and summaries into vectors for subsequent recall
3. **Memory intensity update** — exponential decay model mimicking Ebbinghaus forgetting curve

## Ebbinghaus-inspired forgetting

MemoryBank incorporates a memory updating mechanism inspired by the Ebbinghaus Forgetting Curve to selectively preserve memory.

## Evaluation methodology (RELEVANT FOR v0.7 GOLD-SET)

- **Qualitative:** real-world user dialogs
- **Quantitative:** simulated dialogs — ChatGPT acts as users with diverse characteristics; generates long-term dialog contexts across topics. Then evaluates empathic response + memory recall + personality understanding.
- **SiliconFriend chatbot:** demonstration vehicle, tuned with psychological dialogs.
- **Versatility:** ChatGPT, ChatGLM, BELLE — both closed and open-source LLMs.
