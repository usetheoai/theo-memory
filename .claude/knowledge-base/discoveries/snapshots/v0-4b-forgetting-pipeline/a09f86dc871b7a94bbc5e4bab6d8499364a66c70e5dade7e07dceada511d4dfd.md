# Duolingo halflife-regression — Half-Life Regression (HLR) summary (extracted 2026-05-26)

Source: github.com/duolingo/halflife-regression (Settles & Meeder, ACL 2016 — A Trainable Spaced Repetition Model for Language Learning)

Formula for probability of recall (cited via WebSearch synthesis 2026-05-26, also widely documented in spaced-repetition literature):
    p = 2 ^ (- Δ / h)
where:
    p  = predicted probability of recall (0..1)
    Δ  = time elapsed since last review (same units as h)
    h  = estimated half-life (memory stability)

Equivalent exponential form (using ln 2):
    p = exp(- (ln 2) * Δ / h)

So Ebbinghaus EXPONENTIAL with parameter λ = ln(2)/h. The half-life h is the value at which p drops to 0.5.

Implementation params (from experiment.py per WebSearch synthesis):
- MAX_HALF_LIFE = 274 days (≈ 9 months)  — used as cap for predicted h.
- method = "hlr" (vs baseline logistic regression)
- learning rate = 0.001, hlwt (half-life regularization) = 0.01, L2 = 0.1, sigma = 1.0

Features used by HLR in Duolingo production:
- Recency (time since last review, Δ)
- Frequency (number of past reviews)
- Per-user, per-word skill state

Related algorithms in the same family (per WebSearch synthesis):
- SuperMemo SM-2 (Anki) — ease factor + interval multiplier; deterministic; not data-driven
- Ebisu v2 — Bayesian update of half-life on each review
- DASH (Difficulty, Ability, Study History) — multi-factor extension

Debate (per arXiv 2506.12034): power-law fits modern MLP retention better than pure exponential, but exponential is the canonical baseline and the form Duolingo HLR uses.
