# node-lru-cache Summary (extracted 2026-05-26)

(1) Current Major Version: 11
(2) License: BlueOak-1.0.0
(3) Brief API Description:
- TTL Support: Yes. "This is not primarily a TTL cache, and does not make strong TTL guarantees." Items treated as missing when expired; deleted on fetch.
- Max Size: Supported via `maxSize` parameter with `sizeCalculation` method.
- Fetch-on-Miss: Yes, via `fetchMethod` for "stale-while-revalidate type of behavior."
- Disposal Callback: Yes, `dispose` function invoked when items evicted.
- Eviction Policy: LRU (Least Recently Used). "deletes the least-recently-used items."
(4) TypeScript Types: Yes. "Rewritten in TypeScript" as of version 8; types shipped with package.
(5) Per-Item Access Metadata: Yes. Tracks recency through LRU mechanism. Options include `updateAgeOnGet` and `updateAgeOnHas` to control age refreshing on access.
