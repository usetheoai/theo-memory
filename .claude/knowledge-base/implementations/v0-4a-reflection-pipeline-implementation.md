## Per-task contract

The halt-loop fills the details progressively as it iterates. Each iteration:

1. Reads `.progress-v0-4a-reflection-pipeline.json` to know which task is next
2. Reads the task's full section in `plans/v0-4a-reflection-pipeline-plan.md`
3. SEPA pre-RED brief — surfaces gotchas
4. Writes RED test from plan's TDD block; verifies FAIL
5. Writes minimal GREEN code; verifies PASS
6. SEPA post-GREEN review — SOLID/Clean Code/DRY violations
7. REFACTOR — applies quality fixes; tests stay green
8. WIRING — `check_wiring.py` runs against task's exported symbol; pillars (a), (b), (c) verified
9. SEPA pre-COMMIT audit — DoD checkboxes verified against staged diff
10. COMMIT (conventional-commits, references plan task ID)
11. Updates the row in this file: status → committed; wiring pillars filled; SHA recorded
