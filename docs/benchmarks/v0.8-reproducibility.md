# v0.8 — Reproducibility runbook

Copy-paste commands to reproduce every cell from a clean checkout.

## Prerequisites

```bash
node --version   # >= 20.0.0 (per package.json engines)
npm --version    # bundled with Node 20
# Postgres + pgvector for TheMemory integration tests (optional):
docker compose up -d pgvector   # via npm run compose:up
```

## Install + smoke validation (no API keys required)

```bash
git clone https://github.com/usetheodev/theo-memory.git
cd theo-memory
npm install
npm test                        # 800+ contract tests
npm run test:benchmark          # smoke runs for LongMemEval / LoCoMo / DMR
```

This validates the wiring end-to-end without spending the
30-50 minute cost of a real run. Each smoke fixture is
hand-authored:

- LongMemEval: `tests/e2e/benchmarks/fixtures/longmemeval-smoke.json`
  (3 questions; MIT)
- LoCoMo: `tests/e2e/benchmarks/fixtures/locomo-smoke.json`
  (2 conversations; hand-authored per Drift-T7.1-1 to avoid
  committing CC-BY-NC-SA data)
- DMR: `tests/e2e/benchmarks/fixtures/dmr-smoke.json`
  (2 conversations; hand-authored per Drift-T7.2-1)

## Download fixtures (for full runs)

```bash
npm run download-fixtures
```

This invokes `benchmarks/scripts/download-fixtures.mjs` (EC-6
portable Node 20+ native fetch; EC-8 idempotent HEAD-size check).
Per ADR D4, all 3 datasets download at install time; nothing is
committed to the repo.

URLs (all snapshot-backed at discovery time —
`.claude/knowledge-base/discoveries/snapshots/v0-8-benchmark-methodology/`):

- LongMemEval (MIT): https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned
- LoCoMo (CC-BY-NC-SA 4.0): https://github.com/snap-research/locomo
- DMR (derived from MSC): https://arxiv.org/abs/2310.08560 (REDACTED paper);
  derivation script `benchmarks/scripts/derive-dmr-subset.ts`
  ships as a placeholder per Drift-T7.2-1.

## Run TheMemory full cells (BENCH_RUN=full)

Requires `OPENAI_API_KEY` (and `OPENROUTER_API_KEY` for the claude
judge panel member per ADR D3).

```bash
export OPENAI_API_KEY="sk-..."
export OPENROUTER_API_KEY="..."   # optional; only needed for multi-judge panel
export BENCH_RUN=full
npm run test:benchmark
```

Expected wall-clock per cell (against the full fixture):

- LongMemEval (500 questions × ~3-5s per question): 30-50 min
- LoCoMo (full snap-research fixture): similar order
- DMR (500 conversations × ~2-3s per question): 25-40 min

Results land at `benchmarks/results/{benchmark}/themory.json`
(gitignored; commit only summary back to `docs/benchmarks/v0.8.md`
matrix).

## Reproducibility tolerance

Per blueprint Q6: third-party reproduction should land
within ±5% of published numbers across BLEU + F1 + LLM-judge
accuracy. Wall-clock + cost are environment-dependent and
NOT compared.

When the full cells land, this section will document the
hardware spec used (CPU, RAM, network) so external reproducers
can match.
