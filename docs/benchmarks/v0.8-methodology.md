# v0.8 — Methodology

Companion to `docs/benchmarks/v0.8.md`. Documents how the v0.8 cycle
reasoned about benchmark design, what's load-bearing, and why each
ADR was made.

## ADR trail (D1-D9)

### D1 — v0.8 OWNS the runner; ADOPTS only metric primitives

Inherited from blueprint Q8 finding: no Rule 9 candidate (RAGAS,
DeepEval, LangSmith) ships LongMemEval / LoCoMo / DMR adapters. We
own the runner (`src/benchmarks/runner/`) + the BenchmarkAdapter
DIP (`src/core/dip/benchmark-adapter.ts`); we reuse metric
primitives (`natural.BleuScore`, in-house SQuAD-style F1 +
case-insensitive exact-match). Anti-pattern of standalone adapter
classes with divergent signatures (Mem0's `evaluation/run_experiments.py`
imperative if/elif dispatch) is rejected per blueprint Q1 finding.

### D2 — LongMemEval PRIMARY > LoCoMo SECONDARY > DMR TERTIARY

Per blueprint Q6: LongMemEval (ICLR 2025) has ZERO third-party
reproductions; MIT-licensed data + code; 3.03 GB tractable. v0.8
publication is novel here. LoCoMo is Mem0's apples-to-apples
comparison ground (CC-BY-NC-SA NonCommercial, download-at-install).
DMR ceiling-effects ~93-95% (Zep 94.8% vs MemGPT 93.4% per Zep
paper); included for historical engagement with vendor claims.

### D3 — Multi-judge panel via OpenRouter (no @anthropic-ai/sdk lock-in)

User directive 2026-06-02 rejected Anthropic SDK adoption. claude-sonnet
judges route via OpenRouter (model id `anthropic/claude-3.5-sonnet`)
using the existing `openai` SDK + the `OPENAI_BASE_URL` env-bridge
shipped by the adapters-openrouter-local-embedder cycle (HEAD
`aec5c33`). Default judge panel: `gpt-4o` + `anthropic/claude-3.5-sonnet`
via OpenRouter. Anti-Mem0 prompt design: "Be calibrated, not lenient"
(NOT "be generous"). Regression-guarded by
`src/benchmarks/llm-judge/__tests__/no-anthropic-sdk.test.ts`.

### D4 — Download-at-install for ALL 3 datasets

Per blueprint Q7: LoCoMo CC-BY-NC-SA 4.0 forbids commercial
bundling. LongMemEval HF dataset 3.03 GB inflates clone time. DMR
derived from MSC. All 3 datasets download via
`node benchmarks/scripts/download-fixtures.mjs`
(EC-6 portable Node 20+ native fetch; EC-8 idempotent HEAD-size
check).

### D5 — BenchmarkAdapter Protocol in src/core/dip/; impls in src/benchmarks/

Per `architecture.md § 3` DIP boundaries. Protocol declared at
`src/core/dip/benchmark-adapter.ts` (10th DIP, sibling of
`ConflictResolutionPolicy` from v0.7). Implementations under
`src/benchmarks/{themory,mem0,zep,letta}/` consume the Protocol;
`src/core/` does NOT import from `src/benchmarks/`.

### D6 — BenchmarkAdapter DOES NOT extend MemoryStore (ISP+SRP)

The benchmark protocol accepts arbitrary fixture-shaped corpora +
queries (incl. `expectedSpeakers` per EC-5); MemoryStore is the
internal 3-tier remember/recall surface. Forcing one to inherit
the other would couple v0.8 to v0.0 contract design unhelpfully.

### D7 — tiktoken + pricing-table.json; cost/session not cost/run

`@dqbd/tiktoken` is the canonical JS port of OpenAI's BPE tokenizer
(MIT, WASM, deterministic; per Rule 9 evaluation in plan
Dependencies). `pricing-table.json` carries per-model rates +
`fetched_at` for EC-13 sunset. Drift-T5.1-1 absorbed: cost lookup
uses `SearchResult.modelUsed` (the actual LLM that synthesized the
answer), NOT `adapter.name` — closes EC-3 anti-silent-$0.

### D8 — OTel histogram spans for P95

Every `adapter.add()` + `adapter.search()` call wraps in an OTel
span tagged `benchmark.adapter` + `benchmark.method` (+
`benchmark.question_id`). P95 latency is computed in the
aggregator from span durations (NOT from an OTel histogram metric
instrument). Precedent: v0.4a OTel `ManualReflectionPolicy`.
Local provider per run (NOT `setGlobalTracerProvider`) to avoid
cross-test contamination.

### D9 — Default scorecard = F1 + LLM-judge; BLEU deferred via Drift-T1.1-1; semantic opt-in

Original D9 (v0.8 source plan v1.2) called for BLEU + F1 + LLM-judge,
matching the source persistence shape (blueprint Q2 finding: 8 metric
fns persisted as `bleu1` + `f1` + `llm_score`). v0-8-fixes-cycle-1
fixes-up cycle (2026-06-02) replaces BLEU with `Drift-T1.1-1` deferral
per its ADR D1 — `natural@8.x` removed BLEU entirely (empirical proof
`find node_modules/natural -name '*bleu*'` returned zero matches).
`calculateBleuScore` now throws `BleuMetricUnavailable` so any caller
surfaces the deferral loudly. F1 + Exact Match cover the lexical metric
niche; LLM-judge covers semantic. BERTScore + SBERT-cosine remain
opt-in via `--include-semantic` flag (deferred to follow-up).

**Drift-T1.1-1 marker** — re-introduce BLEU via `v0-8-bleu-vendor-cycle`
(Option B vendor inline, ~30 LoC) IFF v0.8 audience demands BLEU column
post-publication.

## Rejected designs (audit trail)

- **Fork Mem0's runner** — REJECTED per ADR D1; inherits the
  `class Experiment` unused-stub + imperative if/elif dispatch
  anti-pattern (blueprint Q1).
- **Adopt RAGAS / DeepEval as the full runner** — REJECTED per
  Q8 verdicts; neither ships LongMemEval/LoCoMo/DMR adapters;
  both Python-only.
- **Adopt LangSmith Evaluations** — REJECTED; vendor lock-in
  defeats the "independent reproduction" framing.
- **`@anthropic-ai/sdk` for native claude judge access** —
  REJECTED per user directive 2026-06-02. OpenRouter path keeps
  single SDK surface (existing `openai`).
- **`cost via adapter.name`** — REJECTED at Drift-T5.1-1 because
  it silently fabricated $0 cost for TheMemory while vendors got
  real cost. Replaced by `result.modelUsed` (the actual LLM that
  synthesized the answer).
