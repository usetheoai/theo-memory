## Latent bug found + worked around (fix pending in the reusable)
The FIRST attempt 403'd at the attestation push (`anonymous token ... themory:pull,push`). Root cause:
the themory build is LONG (Trivy double-build + native onnx/isolated-vm compile, ~14 min cold) →
the GHCR token obtained at the `Login to GHCR` step (job start) EXPIRES before the attestation push
at the end → buildkit re-auths anonymously → 403. The other 3 packages (theo-mcp-gateway, theo-cloud,
theo-dashboard) build fast (no Trivy double-build) → within the token TTL → fine.

Re-running with a WARM gha cache made the build fast → push within TTL → SUCCESS.

**Permanent fix (in `theo/build-publish.yml`):** move the `Login to GHCR` step to AFTER the slow
Trivy "build-for-scan" (right before `Build + push`) so the token is fresh at push time. Applied
separately.
